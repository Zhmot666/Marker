# Маркировка

Конфигурация 1С для работы с системами маркировки товаров (Честный Знак, операторы ЕАЭС).

## Содержание

- **src/** — исходники модулей (BSL): документы, справочники, регистры, общие модули, конфигурация.
- **docs/** — описание этапов разработки (метаданные, справочники, документы, очередь обмена, форматы API операторов).

## Назначение

- Заказ кодов маркировки и поступление кодов от операторов.
- Очередь обмена, логирование обращений к API.
- Поддержка нескольких стран/операторов (в т.ч. Казахстан, Узбекистан).
